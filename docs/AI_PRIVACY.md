# AI Privacy

Phase 11 stores only the data needed for review, audit, and traceability.

- Long prompts and uploaded document text are truncated before persistence.
- Temporary document records include retention metadata for cleanup workflows.
- Provider usage records store provider, model, token counts, estimated cost, user, college, job, and success/failure status.
- Ordinary faculty see tenant-scoped workflow data only.
- Platform-wide AI usage is reserved for authorized administrators.
- Uploaded document content should not include unnecessary personal data.
