# CampusTest Pro Phase 1 and Phase 2

## Phase 1

The platform uses npm workspaces with separate frontend and backend applications. The web app is a strict TypeScript Next.js project. The API is a strict TypeScript NestJS project with health, readiness, and Swagger documentation.

## Phase 2

The API owns the Prisma schema and seed workflow. PostgreSQL and Redis run locally through Docker Compose.
