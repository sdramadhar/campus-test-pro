# Monitoring

Phase 17 adds Prometheus and Grafana foundations under `infrastructure/monitoring`.

Dashboards to maintain:

1. Platform Overview
2. Exam Operations
3. API Performance
4. Database Health
5. Redis and Queues
6. Worker Jobs
7. Code Runner
8. AI Workflows
9. Proctoring Operations
10. Report Generation

Metrics must not use student answers, source code, hidden tests, tokens, evidence keys, or direct student identifiers as labels.
