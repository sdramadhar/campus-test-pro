# Enterprise Security Audit Checklist

- Authentication and refresh-token rotation
- Role authorization and tenant isolation
- IDOR checks on every tenant object
- CSRF cookie posture
- XSS-safe rendering and CSP
- SQL injection resistance through Prisma
- SSRF controls for imports and provider calls
- File upload MIME, size, malware hook, and private storage
- CSV injection protection
- Secret storage and rotation
- Evidence access audits
- Hidden test protection
- Code-runner isolation
- Audit logs
- Backup encryption
- Rate limiting and WAF rules
- Incident response

This checklist is not a third-party certification.
